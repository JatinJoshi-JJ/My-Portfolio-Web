# 🚀 Jatin Joshi | Premium Web Developer Portfolio

Welcome to my personal portfolio repository! This project is a showcase of my skills, projects, and creative development journey, built with modern web technologies and a focus on premium, interactive design.

## ✨ Features

- **🎨 Premium UI/UX:** Awwwards-inspired design featuring stunning glassmorphism, dynamic gradients, and smooth scrolling.
- **🎬 Cinematic Animations:** Powered by `framer-motion` for immersive enter/exit effects and hover micro-interactions.
- **🌧️ Custom 3D Rain Canvas:** A high-performance, hardware-accelerated rain effect running on the HTML5 Canvas in the background.
- **⚡ Next.js App Router:** Built for speed, SEO optimization, and seamless page routing.
- **📱 Fully Responsive:** Carefully crafted layouts that look perfect on desktops, tablets, and mobile devices.

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (React)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Deployment Ready:** Optimized for platforms like Vercel or Netlify.

## 🚀 Getting Started

First, clone the repository and install dependencies:

```bash
git clone https://github.com/JatinJoshi-JJ/portfolio-website.git
cd portfolio-website
npm install
```

Next, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
